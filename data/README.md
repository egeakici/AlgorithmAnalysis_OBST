# Input Data

This directory contains sample inputs for the Optimal Binary Search Tree
project.

`sample_input.txt` uses the simple text format:

```text
n
key probability
key probability
...
```

`sample_input.csv` uses:

```csv
key,probability
10,0.10
```

Keys must be unique and strictly increasing. Probabilities must be
non-negative and sum to approximately `1`.
